# Eyebrow

Uppercase Space Mono label set above a heading, as a table header, or as a stat caption.

- Always in the muted ink for its surface (`ink-muted`, `on-block-muted`, or `on-volt`); never in volt, which fails contrast as text.
- Separate items with a middle dot: "CAN STACK · ISO-TP · UDS".
- `space-4` (16px) below it before a heading; `space-1` (4px) after a stat value.
- Keep it to one line and under 40 characters.
