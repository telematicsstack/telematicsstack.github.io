# StatBlock

One measurable claim as a big Archivo Black value over a mono caption, in a square bordered tile.

- The value is the fact as measured: "0", "1 KB", "<30 KB", "2010+", "No wire". Six characters or fewer; longer values become a FeatureCard spec line instead.
- Compose blocks in a grid at `space-2` (8px) gap. Mix tones: one `volt` for the lead number, `block` for the second, `outline` for the rest. Never two volt blocks in the same group.
- Captions are lowercase phrases in the eyebrow style ("crashes in production"); the component uppercases them.
- Stat blocks are not links or buttons. If a number needs a destination, put a Button after the group.
