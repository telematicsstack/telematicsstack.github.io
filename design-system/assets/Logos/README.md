# Logos

All files are outlined SVG (no font dependency) and use the exact token values: ink #0A0A0A, ground #F4F4F0, volt #D4FF3A.

| File | Use |
| --- | --- |
| `lockup-horizontal.svg` | Default. Headers, footers, documents, email signatures. On `ground` or `surface`. |
| `lockup-horizontal-reversed.svg` | On `block` (black) panels and dark theme. Ivory tile and text, volt top bar. |
| `lockup-horizontal-mono.svg` | Single-ink black for print, embossing, laser-etched enclosures, and over photography on a solid panel. |
| `wordmark-stacked.svg` | Covers and hero only. "TELEMATICS" over "STACK" with the volt highlighter bar. Minimum width 240px. |
| `mark.svg` | Favicon, app icon, avatar. Black tile, volt top bar, ivory bars. Minimum 24px. |
| `mark-on-volt.svg` | Mark on a volt tile with black bars, for the volt button and volt surfaces. |
| `mark-mono.svg` | Bars only in ink, no tile, for single-colour and small-size contexts. |

Clear space is one bar-height (the height of the top bar) on all sides. Do not recolour, rotate, outline, add shadows, or re-set the wordmark in another face.
